# Research documentation

This folder contains supporting documentation for the provider selection, comparison framework, and evidence records.

- `benchmark-variables-and-coding-rules.pdf` — capability variables, coding rules, and composite measures.
- `provider-cohort-selection-log.pdf` — provider selection criteria and cohort log.
- `evidence-log-structure.pdf` — evidence-log fields and structure.
- `evidence-log-guide.md` — descriptions of the evidence-log fields.
