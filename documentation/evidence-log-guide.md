# Evidence-log structure

Source: *Thesis_2026.pdf*, Appendix 5, p. 99 (Table A5-1). This document describes the fields used in the evidence log; **it is not the underlying 2,061-row source register**.

| Field | Purpose |
| --- | --- |
| Provider and evidence ID | Identifies the company and the individual evidence record. |
| Capability or market topic | Links the record to the relevant comparison area. |
| Claim or observation | Records the provider claim, external confirmation or researcher observation. |
| Supporting detail | Adds the context needed to understand the claim. |
| Current or future status | Separates current capability from announced or planned items. |
| Evidence type and verification status | Distinguishes provider material, external corroboration and direct observation. |
| Evidence strength | Records the 0–5 confidence judgement. |
| Source title, URL and dates | Makes the evidence traceable and time-bound. |
| Caveat or verification boundary | States what the evidence does and does not confirm. |
| Dataset file | Links the extracted record back to the provider workbook. |

The underlying complete source register is referenced by the thesis as part of the supplementary workbook; it has **not** been reconstructed or uploaded here. Evidence strength concerns quality of support for a statement, not whether the capability is favorable. See `benchmark-variables-and-coding-rules.pdf` for state coding and composite-measure definitions.
